## 💻 Installation

```bash
# Clone the repository
git clone https://github.com/sitarambmore/My-Family-Expense-Tracker.git

# Navigate to the directory
cd My-Family-Expense-Tracker

# Install dependencies
npm install

# Start the development server
npm start

## 🛠️ Usage

Open `index.html` in a web browser. That’s it!

No build steps or server required.
